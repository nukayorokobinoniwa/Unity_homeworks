# 視認性を極力悪化させたスイカゲーム

極端に視認性を下げたスイカゲームです。ランキング表示&登録機能も作りました。

## 1. ゲームの遊び方（ルール）

- WASD(矢印キー): 白黒表示のパズルオブジェクトを出す場所を移動させる。
- スペースキー: 白黒表示のパズルオブジェクトを出す。

| レベル | 表記 | 合成時スコア |
| :--- | :--- | :---: |
| Level 0 | 〇 | 10 |
| Level 1 | ● | 20 |
| Level 2 | ●〇 | 40 |
| Level 3 | ●● | 80 |
| Level 4 | ●〇〇 | 160 |
| Level 5 | ●〇● | 320 |
| Level 6 | ●●〇 | 640 |
| Level 7 | ●●● | 1280 |
| Level 8 | ●〇〇〇 | 2560 |
| Level 9 | ●〇〇● | 5120 |
| Level 10 | ●〇●〇 | 10240 |

- ボールが皿からこぼれたらゲームオーバーです。

## 2. ランキング登録について

- 名前の入力: ゲーム中の「名前入力欄」に、あなたの名前（英数字のみ）を入力してください。

- 自動送信: ゲームオーバーになると、入力されている名前とスコアが自動的にオンラインサーバーへ送信されます。

- デフォルト設定: 名前が空欄の場合は「player」という名前で登録されます。

- ランキング閲覧: 起動時およびゲームオーバー後に、最新のトップ10ランキングが表示されます。

## 3. 技術的な特徴

- サーバーレス連携: Google Apps Script (GAS) を介して、データベースとして Google スプレッドシートを使用しています。

- 通信機能: UnityWebRequest を用いた非同期通信により、ゲームプレイを妨げずにスコアの送受信を行います。

## 4. 開発環境

- Unity 6000.0.33f1

- Language: C#

- Backend: Google Apps Script / Google Sheets
